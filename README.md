# OpenCV AI Редактор

Программа для обработки изображений через OpenCV с управлением на естественном русском языке. Нейросеть (Qwen через LM Studio) переводит текстовую команду в pipeline OpenCV-операций.

## Как это работает

```
Пользователь: "поверни на 90, сделай чб и размой лица"
       ↓
   LM Studio (Qwen2.5)
       ↓
[{"function": "rotate_image", "args": {"angle": 90}},
 {"function": "convert_to_grayscale", "args": {}},
 {"function": "blur_faces", "args": {}}]
       ↓
   OpenCV выполняет
       ↓
  input1_result.jpg
```

## Требования

- Python 3.8+
- [LM Studio](https://lmstudio.ai/) с загруженной моделью Qwen2.5 и запущенным Local Server

```bash
pip install opencv-python requests numpy pillow
```

## Запуск

1. Запусти LM Studio → вкладка **Local Server** → **Start Server**
2. Положи изображения в папку с проектом
3. Выбери способ запуска:

### С графическим интерфейсом (рекомендуется)

```bash
python gui.py
```

Откроется окно с двумя панелями — исходное фото и результат. Выбери файл кнопкой 📂, введи команду и нажми **Выполнить** или **Enter**.

### Через консоль

```bash
python main.py
```

Программа предложит выбрать файл из папки и введёт команду в терминале.

## Поддерживаемые команды

| Команда | Пример запроса |
|---|---|
| Поворот | "поверни на 90 градусов" |
| Изменение размера | "сделай 800 на 600" |
| Чёрно-белое | "переведи в чб" |
| Выделить канал | "оставь только красный канал" |
| Размытие | "размой с силой 21" |
| Размытие лиц | "скрой лица" |
| Выделение краёв | "выдели края" |
| Сложение изображений | "сложи с input2.jpg" |
| Смешивание | "смешай с input2.jpg на 70 процентов" |
| Вычитание | "вычти input2.jpg" |
| Побитовое AND/OR/XOR | "сделай xor с input2.jpg" |
| Инверсия | "инвертируй цвета" |

Команды можно комбинировать: *"поверни на 180, выдели красный канал и размой"*

## Структура проекта

```
├── gui.py           # Графический интерфейс (рекомендуемый запуск)
├── main.py          # Консольный запуск
├── ai_bridge.py     # Связь с LM Studio, формирование JSON-плана
├── processor.py     # OpenCV-операции
├── face.xml         # Каскад Хаара для детекции лиц (blur_faces)
└── README.md
```

## Известные особенности

- Имена файлов с кириллицей поддерживаются корректно
- Результат сохраняется рядом с исходным файлом с суффиксом `_result`
- Для команды "размой лица" необходим файл `face.xml` — скачать можно [отсюда](https://github.com/opencv/opencv/blob/master/data/haarcascades/haarcascade_frontalface_default.xml)
